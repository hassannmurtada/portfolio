# Hassan Murtada · Portfolio

Robotics software, sensor to wheel. Live at **https://hassannmurtada.github.io/portfolio/**

A single hand-written page: no framework, no build step, no cookies.

## What's in here

| File | What it is |
|---|---|
| `index.html` | The whole site: markup, styles and scripts |
| `404.html` | The "nothing detected" page shown for broken links |
| `media/` | Compressed screenshots, the on-road clip and the link preview card (`og-card.png`) |
| `BasketballRobot.jpeg` | Photo of the ABU Robocon 2025 robot |

To change something, edit `index.html` and push to `main`. GitHub Pages publishes it within a minute or two.

To preview locally, open `index.html` in a browser. Visits from your own computer's files are not counted.

## Visitor stats

Stats are collected with [GoatCounter](https://www.goatcounter.com). It sets no cookies and does not identify people. The dashboard is private: **https://hassannmurtada.goatcounter.com**

To stop counting your own visits, open the site once per browser with `#toggle-goatcounter` at the end of the address.

### Tagged links: know where each visitor came from

Add `?ref=` and a label when you share the link. The label shows up in the dashboard under **Campaigns** (or **Referrers**, depending on your GoatCounter version).

| Where you share it | Link to use |
|---|---|
| CV / résumé PDF | `https://hassannmurtada.github.io/portfolio/?ref=cv` |
| LinkedIn profile | `https://hassannmurtada.github.io/portfolio/?ref=linkedin` |
| GitHub profile | `https://hassannmurtada.github.io/portfolio/?ref=github` |
| Email signature | `https://hassannmurtada.github.io/portfolio/?ref=email` |
| A specific application | `https://hassannmurtada.github.io/portfolio/?ref=companyname` |

Use a different label for each application to see which companies opened the link.

### What gets recorded

Page views record country and region, referring site, browser, system and screen size.

Events appear in the **Pages** list. Each one counts at most once per visit, so a number means "visitors who did this".

| Event | Meaning |
|---|---|
| `engaged-30s`, `engaged-1min`, `engaged-3min` | Kept the page open and visible for that long |
| `reached-projects`, `-lessons`, `-work`, `-skills`, `-journey`, `-contact` | Scrolled as far as that section |
| `nav-…` | Used the top menu to jump to a section |
| `click-hero-see-work`, `click-hero-email`, `click-hero-github` | Buttons at the top of the page |
| `click-contact-email-copy`, `click-contact-email-open` | Copied the email address, or opened a new email |
| `click-contact-phone`, `click-contact-linkedin`, `click-contact-github` | Contact links |
| `click-repo-vision`, `click-repo-mainboard` | Opened a code repository |
| `click-out-…` | Any other external link |
| `watched-onroad-video`, `finished-onroad-video` | Video was on screen and playing for 8 s, or to the end |
| `open-autoware-story`, `open-robot-rules`, `open-fusion-note` | Expanded a "full story" section |
| `zoom-…` | Enlarged a screenshot |
| `used-calibration-playground` | Moved the calibration sliders |
| `dropped-lidar-cone` | Tapped the LiDAR map at the top |
| `toggle-theme` | Switched light / dark |
| `printed-page` | Printed the page or saved it as a PDF |
| `404:/…` | Someone followed a broken link to that address |

Reading the numbers: `engaged-1min` plus `reached-contact` is a visitor who read the page. Any `click-contact-…` event is a visitor who tried to reach you.
